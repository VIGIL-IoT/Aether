# Firmware status

The firmware directory contains legacy ESP32/nRF24 sketches. The browser simulator does not compile, load, or communicate with these files.

No sketch has been validated on hardware or reconciled with the pin assignments in carrier R1. Some sketches contain transmitter-capable routines. Treat all firmware here as unreviewed source; do not use it as a working or deployment image.

See [CHANGES.md](CHANGES.md) for provenance limitations and the file list, and [the R1 pin map](../docs/pinout.md) for the current carrier routing. The pin map alone is not a firmware validation.
