# Experiment 02: distance and packet delivery proposal

**Status: proposal only.** No distance, packet-loss, or range measurements have been conducted. The historical expected values and conclusions previously written here were unsupported and have been removed.

The proposed question concerns how physical separation affects packet delivery for a specified pair of radios. The browser model has no packets, receiver, propagation model, or distance input; it cannot answer this question.

Any future physical study needs reviewed transmitter-capable firmware, an authorized environment, a documented device and antenna configuration, measurement equipment, repeatable methods, raw data, and analysis. This page is not an operating procedure.
