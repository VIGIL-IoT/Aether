# Experiment proposals

No Aether RF experiment has been completed in this repository. The folders below are proposals only; there are no raw measurements, analysis outputs, or results. The browser simulator is not a measurement instrument and cannot produce evidence for these proposals.

| ID | Topic | Status |
| --- | --- | --- |
| 01 | Channel selection and channel overlap | Proposal only |
| 02 | Distance and packet delivery | Proposal only |
| 03 | Building-material attenuation | Proposal only |
| 04 | Human-body attenuation | Withdrawn pending independent safety and ethics review |

Any future physical study needs a reviewed method, exact hardware and firmware revisions, qualified equipment, authorization for the test environment, and retained raw data. This repository does not provide operational transmitter instructions. Do not describe an experiment as performed until its evidence is checked in and reviewed.

## Evidence record requirements

A future experiment record should state its question, hypothesis, system under test, equipment and calibration, variables, procedure approval, number of repetitions, raw-data location, analysis code, results, failure cases, limitations, and review date. Clearly distinguish measured results from simulation and theory.

The former generalized instructions and example measurement rows in this directory were not project data and have been removed.
