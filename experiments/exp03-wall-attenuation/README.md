# Experiment 03: building-material attenuation proposal

**Status: proposal only.** No attenuation measurements have been conducted and no material-loss results are available. Earlier numeric conclusions were not supported by checked-in data and have been removed.

The proposed topic is signal change through building materials. The browser model has no propagation, receiver, or material input and cannot answer this question.

A future study requires a reviewed method, approved test environment, calibrated equipment, documented materials and geometry, a validated system under test, raw data, and analysis. This page is not an operating procedure.
