# Experiment 01: channel-overlap proposal

**Status: proposal only.** No hardware experiment has been conducted and no data or result is available.

The earlier protocol proposed comparing nRF24 channel selections under different channel-spacing conditions. The current browser application does not model channel bandwidth, packets, interference, or reception, so it cannot answer that experimental question.

A future study would require a reviewed and authorized setup, defined equipment and radio configuration, validated firmware, repeatable measurement method, raw data, and analysis. This page is not an operating procedure.
