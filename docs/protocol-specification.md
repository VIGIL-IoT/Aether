# Protocol draft status

The packet protocol described in the earlier version of this document is withdrawn. It was a proposal, is not implemented, and contains unsupported fields and assumptions. It must not be treated as a working Aether protocol or used to configure a device.

The current browser app models only channel selection. It does not construct, transmit, receive, encode, or decode packets. There is no implemented multi-node protocol in the repository.

Any future protocol proposal needs a separate engineering review, a defined non-disruptive scope, and a verification plan before it can be documented as an implementation.
